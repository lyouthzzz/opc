# 价值投资 (/价值投资)

触发 `价值投资` skill，按 `$ARGUMENTS` 指定的公司与问题选择快速判断、完整分析或跟踪复盘。

## 必须做的事

1. **读取并遵循主 skill**：在本仓库优先读取 `skills/价值投资/SKILL.md`；安装后按当前 Agent 的技能目录解析。未被发现时，再检查项目级 `.claude/skills/价值投资/SKILL.md`、`.cursor/skills-cursor/价值投资/SKILL.md` 或对应 Agent 的全局 skills 目录。
2. 将 `$ARGUMENTS` 中的标的、问题、日期和输出偏好传给主 skill；公司分析需要标的但无法从对话确定时，只询问缺失的标的。概念问题不要求提供公司。
3. 数据来源、参考文件、分析深度和结论规则均以主 skill 为准：每次独立研究，核验当前时间、最新行情、最新已披露财报和期后公告，不默认读取旧知识库或旧报告；先判断估值条件，再按证据比较存量业务与增长贡献。本命令不另设数据源限制、固定评分或重复分析流程。
4. 按主 skill 交付：公司分析默认生成独立 HTML，普通概念问题可直接回答，用户指定格式时遵循其要求。回复附报告链接与简短结论。

## 使用方法

```text
/价值投资 贵州茅台
/价值投资 600519.SH
/价值投资 泡泡玛特 09992.HK
```

## 不要做的事

- 不构成投资建议；市场数据仅供参考。
- 看不懂的生意可以 skip，不勉强给结论。
- 不将一家公司的结论机械套用到另一家。
