# 价值投资框架

本文件补充价值投资 skill 的分析方法，围绕段永平/巴菲特投资理念中的生意、管理层和价格展开。每次分析从本次核验的原始资料重新建立判断；不读取旧公司知识库作为案例依据或默认背景。任务路由、估值条件、结论状态与交付格式以主 skill 为准。

---

## 一、投资哲学基础

### 买公司，就是买公司未来的现金流

核心问题是未来现金流的规模、到达时间、持续性、风险，以及股东能分享的比例。商业模式决定现金创造能力，护城河影响其持续时间，管理层决定现金配置与归属，买入价格决定投资者为这些现金流付出的成本。

分析按以下顺序展开：

1. **现金来源**：谁付钱、为何持续付钱、多久回款，收入和利润如何转成经营现金流。
2. **必要投入**：维持当前经营与竞争力需要多少资本开支和营运资金；实现预测增长还需要追加多少投入。
3. **现金归属**：考虑债权人、少数股东、受限资金、监管资本要求和股本稀释后，普通股股东能分享多少。
4. **资本配置**：留存再投资是否增加未来现金流现值；分红与回购是否合理，回购价格与净股数变化如何。
5. **时间与风险**：现金何时产生、可以持续多久，哪些竞争、经营或治理变化会使预测失效。

完整研究把这些问题落实为经营驱动、正常化现金流调整、增长所需投入和每股价值桥接。先判断证据是否足以估值；可定量时比较存量业务与增长路径，辨认价格依赖哪些尚未兑现的经营条件。估值条件、对照方法、公式和防止重复计价的检查统一放在 [从商业判断到股东价值](business-to-value.md) 中，不以概念说明代替可复算的推导。

分红是兑现路径之一。今天的低分红或低自由现金流可能来自有价值的再投资，也可能来自经营恶化，必须检查增量回报及未来现金兑现证据。回购减少股数但也消耗现金，应结合价格判断其对每股价值的影响。

方法来源：[伯克希尔 1986 年股东信](https://www.berkshirehathaway.com/letters/1986.html)末尾对业主收益及必要资本投入的说明；[2007 年股东信](https://www.berkshirehathaway.com/letters/2007ltr.pdf)“Businesses – The Great, the Good and the Gruesome”对护城河、资本回报及再投资需求的讨论。本文的执行流程是研究方法整理，不应整体归为某位投资人的原话。

### 核心三要素：Right Business, Right People, Right Price

分析顺序是先判断生意与管理层，筛出能理解且现金流有可信依据的企业，再判断价格。质量筛选通过后，仍须比较未来现金流现值与当前价格，完成 Right Price 判断。

- **Right Business**：好生意。能持续赚钱、有护城河、能穿越周期的商业模式。
- **Right People**：好的人。管理层诚信、有能力、有长期主义思维、做对的事情。
- **Right Price**：好价格。相对于未来现金流和不确定性，价格有足够的安全边际。

### 本分与理性想长远

段永平投资体系的核心文化：

- **本分**：做该做的事情，不赚不该赚的钱。本分经营是对股东最好的回报。
- **理性想长远**：想长远所以必须理性，保持理性就必须有平常心，隔绝外部压力和诱惑。三者形成闭环。
- **做对的事情，把事情做对**：
  - "做对的事情"（do the right things）是方向性问题，最重要
  - "把事情做对"（do things right）是执行力问题
  - 做对的事情的重要性 > 今天融了多少钱

### 长期主义

- "相信时间的力量，慢慢来、慢慢做，但要做就要做好、做对"
- 长期价值取决于未来可归属股东的现金流折现总和，须同时考虑规模、时间、持续性和风险。
- 预测增长时必须计入所需再投资；只有增量投入创造的未来现金流现值超过投入成本，增长才创造价值。
- 短期增速放缓不必然损害长期价值，应检查现金创造能力与竞争地位是否发生实质变化。

### 客户价值与经济回报

区分使用者、购买决策者与付款人，说明公司解决了什么问题，客户为何愿意持续付费，以及竞争后公司能留下多少现金回报。ToB 与 ToC 的采购周期、议价权和服务成本不同，不能按客户类型预设生意优劣；消费者导向也需要由复购、留存、定价与回报证据验证。

## 二、看懂生意的方法论

### 什么是"看懂"

"看懂"不是知道公司做什么产品，而是理解：
1. 公司的本质是什么（不是什么）
2. 核心需求是什么（功能性 vs 情绪/精神）
3. 商业模式如何运转（钱从哪来到哪去）
4. 哪些竞争与需求条件支撑长期现金流，哪些变化会破坏它（可持续性）

用主要业务的收入驱动、单位利润、周转与投入建立因果模型，并说明哪些变化足以改变判断。护城河的证据与估值假设之间要有明确传导，操作方式见 [经营假设与关键分歧](business-to-value.md#一把商业判断变成经营假设)。

### 看不懂可以 skip

- "人生很忙，看不懂的东西是可以 skip 的"
- 不必勉强投资看不懂的公司
- 对决定结论的疑点做有针对性的研究；仍无法建立可验证的因果模型时，说明能力圈限制，不以无限搜集资料拖延判断

### 如何深入理解一家公司

1. **围绕关键问题读披露资料**：先读业务、财务报表、风险、治理及相关附注，异常项追溯到解释它的原文。
2. **对照管理层说法与经营结果**：采访、视频和指引提供待验证的主张，不能独立证明护城河或诚信。
3. **补充客户与渠道证据**：可使用用户提供的调研、公开客户资料或有来源的第三方观察，说明样本局限，不声称完成未实际开展的实地调研。
4. **检验相反解释**：同一组收入、利润和现金流变化是否可能来自周期、一次性因素或会计处理。
5. **形成暂定判断**：说明哪些问题已解决、哪些证据缺口会改变结论，再决定是否需要继续研究。

### 破除常见误区

- **混淆品牌和品类**：消费者常把品牌当品类的代名词，这是品类创新者必须接受的荣耀和考验
- **用功能产品思维看情绪产品**：情绪价值产品的逻辑与功能产品不同
- **用指引习惯判断质量**：是否给指引不能单独证明管理层优劣，应检查假设、兑现记录和修订解释
- **被"加速度"迷惑**：增速放缓 ≠ 业绩恶化，要看绝对值和趋势

## 三、五维度分析方法

五维度是展开三要素的可选检查表，不是必须评分的第二套决策系统。商业模式、市场规模和竞争壁垒归入 Right Business，企业文化归入 Right People，估值归入 Right Price。若评分，按主 skill 附证据和置信度；不以机械平均分掩盖关键缺陷。

### 维度一：商业模式

**评估清单**：

| 指标 | 关注点 | 判断依据 |
|------|--------|----------|
| 收入结构 | 产品、客户、地区和渠道集中度 | 集中带来的风险与专注优势；不默认多元化更好 |
| 毛利率/净利率 | 同口径的同业与历史趋势 | 定价、成本、业务组合和周期解释；不设全行业统一门槛 |
| 利润含金量 | 多年利润到经营现金流的桥接 | 应收、存货、预收、应付及一次性变化；高现金流也须解释来源 |
| 资产结构 | 债务期限、利息、现金可用性 | 下行情景下的偿债与再融资能力；不能仅看账面净现金 |
| 资本回报 | ROIC/ROE 及增量投入的回报 | 披露计算口径，解释杠杆、回购与会计影响，不将高 ROE 直接视为高经营回报 |
| 定价权 | 价格、销量、客户留存和替代品 | 提价后需求与利润的实际变化，而非仅看产品知名度 |
| 规模经济 | 单位成本与服务、获客、履约投入 | 扩张后单位经济是否改善，是否依赖持续补贴 |

**关键判断**：需求、竞争优势和必要投入能否共同支持持续的股东现金流；若依赖爆款或少数客户，要估计失去它们的影响。

### 维度二：市场规模

**评估清单**：
- 行业总规模（TAM）及增速
- 公司市占率及 CR5 集中度
- 天花板距离：还有多少倍空间
- 国内 vs 海外收入占比及增速差异
- 增长驱动因素：扩张驱动 → 精细化运营驱动 → 平台驱动

**关键判断**：
- 公司实际可服务的需求有多大，份额增长需要哪些产品、渠道和资本投入？
- 新区域或新业务的单位经济是否成立，多久能产生现金？
- 市场增速放缓来自需求、渗透率还是竞争，怎样影响未来回报？

大 TAM 不能直接变成公司收入预测，成熟市场中的稳定现金创造也不能仅因增长慢而被否定。

完整研究按 [公司与行业时间线](company-and-industry-trends.md) 对照行业近年与最新同期变化、公司份额和竞争，再解释未来 3–5 年需求如何经过利润率与必要投入转成每股现金回报；历史事实、公司指引、外部预测与研究假设分开标注。不能只给某年的市场规模或预测 CAGR 就结束行业分析。

### 维度三：竞争壁垒

**护城河类型**：

1. **品牌与无形资产**：信任、认知、授权等能否带来持续付费或定价优势，需与营销投入和替代品比较
2. **网络效应**：新增参与者是否提高其他用户的价值，需区分网络效应与一般规模、数据积累效应
3. **规模优势**：供应链柔性、成本结构、渠道密度
4. **转换成本**：迁移、重新培训、流程重建等真实代价；有会员或历史投入并不自动证明转换困难
5. **资源独占**：签约顶尖人才、核心位置门店、独占性资源

**资源聚集现象**（有时比喻为“黑洞效应”）：
- 头部资源主动向公司汇聚
- 新锐创作者/人才纷纷投奔
- 可能形成正反馈循环；仍需检查后来者能否通过替代渠道或技术进入

**壁垒的局限性**：
- "壁垒不能保证需求永远存在，但可以让有需求的人持续关注公司"
- 壁垒 vs 持续性：壁垒已建起来，大家要顾虑的是持续性问题

这些类型是待验证的机制，不能见到会员、用户增长或人才聚集就判定壁垒成立。至少说明该机制怎样抵御竞争、延长现金流持续时间，并给出可观察证据及失效路径；“黑洞效应”仅是资源聚集的比喻，不是确定性评级。

### 维度四：企业文化与资本配置

从重要决策记录观察文化，不按创始人的性格、演讲风格或名望评分：

| 维度 | 核验证据 | 反证方向 |
|---|---|---|
| 诚信与披露 | 原承诺、后续结果、偏差解释及更正记录 | 选择性披露、反复更换口径、隐瞒重大问题 |
| 再投资与并购 | 投入金额、预期回报、兑现进度与退出决定 | 无约束扩张、长期低回报、忽略机会成本 |
| 股东分配 | 分红、回购价格、净股数及每股现金创造变化 | 回购被稀释抵消、为分红牺牲偿债能力 |
| 治理与激励 | 关联交易、报酬、控制权和中小股东待遇 | 利益输送、不对称承担损失 |
| 纠错与组织 | 失败项目调整、责任机制与接班安排 | 固守沉没成本、经营依赖不可替代的单一人物 |

“长期主义”“本分”等自述作为研究线索。无法找到可核验的行为记录时，保留判断并降低置信度。

### 维度五：估值

方法选择遵循主 skill 的公司类型表，不存在通用的“合理 25 倍 PE”。先检验现金流起点、增长投入与股东归属，再估值；财务公式不能补足缺失的商业证据。

先执行 [估值条件判断](business-to-value.md#估值条件判断)，再按 [存量业务与增长贡献的对照](business-to-value.md#存量业务与增长贡献的对照) 解释价值来源。可估值时将经营路径转为情景区间；可做边界判断时检验结论是否跨合理范围成立；暂不可估值时说明经营门槛和关键缺口，不默认制作每股条件价表。价格判断均应能追溯到同一套底稿，历史低倍数不能单独证明便宜。

## 四、四种好运理论

这是讨论产品试错、能力积累与资源吸引的可选观察视角；使用时须以本次核验的经营证据建立判断，不加载旧公司案例。不作为所有行业的必填项，不据此直接得出投资或仓位结论。若要引用其作者或原话，需另行核验原始出处。

### 第一种：完全随机的好运

- **定义**：纯粹偶然、不可控且无法预测的运气
- **特征**：持续时间与可复制性需要证据，不能预设固定期限
- **企业对应**：外部事件催化（如名人自发分享、政策红利、突发事件）
- **投资含义**：不可依赖，不能作为投资依据

### 第二种：数量保质量的好运

- **定义**：多产生作品/产品，用数量确保质量，尝试越多成功概率越大
- **企业实践**：
  - 小批量生产 → 测试市场反应 → 爆款追加资源、弱品直接砍掉
  - 储备大量创作者/产品线，形成"金字塔式梯队"
  - 从"赌一个"变成"测一批、选最优"
- **投资含义**：系统化的试错机制，成功率可提升

### 第三种：更高作品质量的好运

- **定义**：持续提高自身能力，用能力保质量
- **企业实践**：
  - 内部研发/设计团队辅助打磨产品
  - 分成/股权模式绑定长期合作
  - 提炼核心辨识度，工业化优化
- **投资含义**：能力建设是可持续的

### 第四种：专家身份让好运找上门

- **定义**：成为某个领域的专家/领导者后，机遇和资源主动来找你
- **企业实践**：
  - 行业共识：头部创作者/人才更愿意和领先公司合作
  - 正反馈循环：头部资源汇聚 → 产品更强 → 吸引更多资源
  - "黑洞效应"：行业最优质的资源持续向公司汇聚
- **投资含义**：检验资源聚集是否能转化为持续现金回报，以及资源是否可能转向竞争者

### 综合判断标准

| 观察到的机制 | 仍需核验的问题 |
|-------------------|-------------|
| 主要依赖外部偶然事件 | 移除催化后，需求与利润是否仍成立？ |
| 有持续试错机制 | 试错成本、成功率与成功产品寿命怎样？ |
| 能力积累与资源汇聚 | 是否在多轮产品或周期中创造了可重复的现金回报？ |

多种机制并存仍只是待验证的解释；需要业绩与反证检验，不能从分类名称推出护城河已成立。

## 五、判断标准与决策框架

### 投资决策树

```
先核实关键事实与能力圈；已证实的重大问题可直接支持“回避”。
   ├─ 决定结论的事实缺失 → 数据不足，保留可支持的局部判断
   ├─ 事实已了解，但无法解释关键因果 → 超出能力圈
   └─ 可继续判断
       ├─ 生意、治理或财务韧性存在实质问题 → 回避
       ├─ 暂不可估值 → 保留局部判断；按缺事实/能力圈等实际原因确定状态，不给候选
       ├─ 价格缺乏安全边际，或结论在合理边界内翻转 → 观察
       └─ 生意、管理层与价格均通过，证据或合理边界足够 → 候选

风险与反证贯穿三要素判断；“候选”不自动等于买入或某种仓位。
```

以上是研究分类，不是首屏文案。按主 skill 的“综合结论”先写易懂判断，再附状态；明确已知事实、关键阻碍、下一次检查及改善/恶化如何改变判断。不能用“数据不足：继续观察”替代这些信息，也不能把尚未取得的公开资料写成企业没有披露。

### 持续性争议的处理

- 持续性争议会长期存在——"在持续性上的争议会持续很久的"
- 企业需要"一直证明下去"——但"他们自己不需要证明什么，只要继续做该做的事情就好"
- "大家可以先看个五年十年吧"——给时间验证
- 用过往认知能力验证新领域——"我很好奇我对 X 的理解会不会在这里再次得到回报"

### 业绩指引与研究假设

管理层指引是带日期、前提和适用期间的陈述；将其与实际结果比较，但不把它当成已经实现的业绩。研究者可建立自己的情景假设，并标明与管理层指引的区别。不能因公司不提供指引而自动提高管理层评分。

## 六、分析输出模板

### HTML 投资分析报告结构（默认输出）

价值投资分析报告默认生成独立 HTML 文件，除非用户明确指定其他格式。根据任务深度精简或扩展下面的结构；快速判断不必填满模板。模板中的注释须替换为实际分析内容，不能作为完成的报告交付。

交付检查：

- 使用完整 `<!doctype html>`、UTF-8、移动端 viewport 和内联 CSS；不依赖 CDN、外部字体或外部脚本，离线打开也可阅读。
- 首屏用完整短句呈现判断与理由，说明已确认什么、什么问题影响进一步判断、下一次具体看什么；公司名、代码、分析日期、辅助状态、置信度和关键指标完整。不要以未解释的“数据不足/继续观察”代替结论。完整报告使用章节导航和清晰的标题层级，快速判断按需简化。
- 可估值时展示存量/增长路径对照和情景区间；可做边界判断时展示有依据的范围与结论稳健性；暂不可估值时以待验证经营门槛和缺口替代价格图表，不把免责声明当成输出无依据目标价的许可。用户明确要求的假设演示单列，不放入结论卡。
- 完整报告按 [时间线规范](company-and-industry-trends.md) 展示默认五个完整财年的业绩趋势、最新同期间对比，以及行业和公司增长对照；依据数据选择现金流桥接和未来路径图表。图表有发现、有原因、有未来含义，不以数字大表替代已有数据可支持的趋势。标明单位、期间、图例和来源，历史与预测分开，缺失值不记零；具体样式见 [报告设计](report-design.md)。
- 使用盈利倍数时，展示报表利润 → 逐项税后归属调整 → 研究正常化利润的桥接，并列报表 PE、公司披露的扣非/经调整口径（相关且可桥接时）与正常化 PE，解释差异；无法计算的口径明确原因，不能省略后仅留下低报表倍数。执行 [盈利正常化与 PE 解释](business-to-value.md#盈利正常化与-pe-解释)。
- 支持窄屏布局、宽表横向滚动和打印样式；可用原生 `<details>` 折叠详细假设，打印时确保关键论据可见。
- 重要数据与论据就近附可点击来源，分别保留数据时点、财报期、公告时间与检索时间；首屏显示分析基准时刻、最终核验时间及关键时效缺口。交付前按市场数据手册复核最新行情和披露，发现新信息时更新相关计算与结论。外部文本先进行 HTML 转义，不执行来源中的脚本或代码。
- 默认保存到当前工作区 `reports/<公司代码>-value-investing-<YYYY-MM-DD>.html`；文件已存在时添加时间后缀，避免覆盖。报告保存不构成以后自动读取的授权，后续分析仍独立重建。
- 检查占位符、数据口径、来源链接与离线依赖；有浏览器预览能力时检查桌面与窄屏效果。回复中给出报告文件链接和简短结论，并在支持时打开 HTML 预览。
