# 市场数据手册：通达信、问财与检索降级

本手册定义价值投资研究的数据收集与核验方法。通达信官方 MCP 和同花顺问财都是可选的结构化数据来源，任一可用即可开始收集；两者均不可用或所需字段缺失时，使用可用的检索工具和用户提供的数据。模型已有知识只可补充稳定的历史背景，不可用于当前市场事实。

## 数据收集顺序

先确认会话当前日期、用户时区和实际执行时刻。默认按本次研究时点收集最新已公开信息；仅用户明确要求历史研究时，才使用该历史时点已公开的数据。以下步骤也适用于快速判断，不得从旧报告日期开始查询。

1. **检查可用能力**：查看当前会话可调用的数据工具及接口说明，仅检查配置是否存在，不输出 Token。通达信使用已配置的官方 MCP；问财按实际工具支持的查询方式调用。不得凭名称假定接口或字段存在；不先查旧公司知识库或旧报告。
2. **确认标的**：统一公司名、证券代码、市场、报价币种和财报币种；存在多地上市或存托凭证时，核对股本及换算关系。
3. **行情与估值**：核对当地交易状态，通过可用工具取得最新可得报价，注明数据时间和延迟；非交易时段使用最近有效交易日收盘价。无可用接口时从可核验的公开来源获取，不接受没有交易日和时间的“最新价”标签。
4. **财务与现金流**：先打开交易所或公司投资者关系的披露列表，确认最新业绩公告、报告期和更正文件，再获取最新披露字段及最近 5–10 年历史。供应商报告期落后时从原始披露补齐；历史不足不补造，年度、单季、累计和 TTM 分开保存。
5. **经营解释、行业与期后更新**：用定期报告及附注补齐分部经营、资本开支性质、受限现金、债务期限和股东分配；检查报告期末至本次核验时刻的重大公告、经营数据及股本变化。完整分析按主要业务采集行业最近 3–5 年及最新可比期间的需求、竞争和供给数据，核验未来增长预测的原发布方与假设；单点问题按需缩减。
6. **核验并形成底稿**：每次从原始披露重新建立事实集，检查币种、单位、归属口径及报告期；关键估值输入和异常值回查原文。发生冲突时先排除不同口径，仍无法解释则保留差异，避免仅以更新时间选值。历史研究的数值、引用和参数不得直接转入本次底稿。
7. **交付前复核**：做一次最新行情和官方披露列表检查；若收集期间已跨交易日或发生新披露，更新受影响的价格、现金、债务、股数和经营假设，重算相关结果后记录最终核验截止时间。

以上为默认路径，用户指定数据源时优先遵循。无需同一字段在两处重复采集。通达信/问财未提供的维持性资本开支、业主收益、未来现金流等须作为分析估计单列，附假设和推导，不能标成供应商原始数据。

采集范围由本次研究问题决定，重点关注经营、现金流、资本配置及价格。快速判断只取影响该问题的字段；市场数据仅补充背景，不以技术指标、资金流或板块热度替代商业质量和价值判断。

## 一、按研究问题选择数据

| 数据类别 | 主要字段 | 研究用途 |
|---|---|---|
| 财务与现金流 | 收入、利润、资本回报、资产负债、经营及投资现金流 | 正常化现金流、必要投入与财务韧性 |
| 公司基础资料 | 公司名称、代码、行业、上市地、股份及权利结构 | 确认标的与股东归属 |
| 行情与估值 | 股价、市值、企业价值、估值倍数、分红 | 与独立估计的价值比较 |
| 同业经营数据 | 同口径的利润率、资本回报、周转、投入与估值 | 检验竞争优势和估值差异 |
| 行业需求与供给 | 同范围的销量/收入、渗透率、价格、产能/利用率、竞争结构及有来源的预测 | 区分行业增长与公司份额变化，约束未来利润、投入与现金回报 |

按字段组查询，先确认工具实际支持的市场、期间和口径；港股等跨市场查询带上代码与市场后缀。某项字段未稳定返回时，切换到原始披露或其他可靠来源，保留来源、日期和口径；仍无法核验时说明缺失。

使用盈利倍数时，同步采集最新损益附注、非经常损益及公司经调整利润对账表，并回查近 3–5 年同类调整。保留项目原始正负号、税前/税后、普通股股东归属、是否现金及发生频率；TTM 的利润和各项调整使用相同的期间与版本。数据商 PE/扣非 PE 只作待核验字段，正常化方法见 [盈利正常化与 PE 解释](business-to-value.md#盈利正常化与-pe-解释)。

## 二、可选环境

通达信使用已配置的官方 MCP。本仓库以 `TDX_API_KEY` 作为 Key 的环境变量名称；配置存在不代表服务可调用，须以实际工具响应确认。不要把第三方同名工具自动视为官方服务，也不要在分析任务中自动修改连接配置。

只有选择使用问财增强时才需要以下环境变量：

```bash
export IWENCAI_BASE_URL="https://openapi.iwencai.com"
export IWENCAI_API_KEY="你的_IWENCAI_API_KEY"
```

未配置或当前会话无法调用时，不要求用户补 Token，也不停止分析；直接使用可靠检索与原始披露。数据研究过程中不自动修改连接配置。

## 三、数据时效性校验

### 3.1 时间锚点与最新性证据

每次分析都先确定：

| 锚点 | 含义 | 获取方式 |
|------|------|----------|
| 当前时刻与分析基准时刻 | 默认是本次执行时刻；明确历史研究时另记历史基准 | 会话当前日期、用户时区和可用时钟；不采用旧文件日期 |
| 行情截止口径 | 行情 / 估值口径的实际时间 | 来源中的交易日、时区及报价时间；交易状态、盘中/收盘及延迟 |
| 最新已披露报告期 | 截至基准时刻已经公开的最新财务披露 | 官方披露列表、报告期、公告时间和更正版本；不能仅看数据商返回期间 |
| 期后公告截止 | 财务报告期末之后的重大变化检查到何时 | 交易所或公司披露列表、公告时间与影响 |
| 检索与最终核验时间 | 本次访问来源与交付前复核的时间 | 实际执行记录；不得冒充数据本身的日期 |

历史时点分析只使用当时已公开的信息；同时保留报告期与公告日，不能因报告期早于基准日就使用在基准日之后才公布的财报。研究后的新信息用于复盘时须另列。

### 3.2 校验规则

1. **行情时点与交易状态相符**：盘中优先最新可得报价，来源有延迟时记录实际报价时间和已知延迟，不能标成实时；只有旧收盘价时仅作为历史参考，不声称已核验当前盘中价格。收盘、周末及节假日使用交易日历确认的最近有效收盘；停牌时记录最后交易时间和停牌状态，不将旧成交价视为当前可成交价格。
2. **财报确为最新已披露**：通过官方列表核验是否已有更新季度、中期、年度业绩或更正公告。最新业绩公告早于完整报告发布时，采用其中已核验的最新指标，缺少的附注继续引用可得旧报告并逐项标明期间。不能因某一旧报告更完整就忽略新业绩，也不能给未披露字段补数。预告、快报、未审计业绩和审计财报分开标识；当前分析处理更正/重述，历史研究只用当时已知版本。
3. **财务时间与经济含义分开**：最新报告期仍是历史期间，不是当日现金或负债余额。对最新已披露期后借款、偿债、分红、回购、增发和并购逐项桥接，避免重复计算；仅“计划/授权/公告”不能记作已完成现金流或股数变化。不能完整桥接时明确缺口，不把旧余额改名为今日余额。
4. **估值各输入分别核验**：股价、市值、股数、汇率、盈利分母与净债务均标明实际时点；检查拆股、除权、回购注销、增发和存托比例变化。TTM 使用最新可得同口径累计数据计算，不拼接不同版本；多公司比较同时展示各自最新报告期，口径不齐时明确可比性限制。
5. **行业数据及经营指标查最新发布**：核对原发布方的最新统计期间、发布日期及修订；月度交付、订单、销量等不能只看旧研究引用。区分发生时间、统计期、公告时间和网页抓取时间，搜索结果排序或网页“今日更新”不能单独证明数据新鲜。
6. **来源切换不降低时效要求**：发现返回旧期间、旧报价或时间缺失时，转查官方披露或其他可靠来源。关键数据的最新性仍无法确认，标记“时效未通过”，保留可支持的局部分析，不给当前便宜程度、安全边际或候选结论。缺最新行情可独立估计有证据支持的内在价值；最新财务或重大事项尚未核实时，则同时重审估值条件状态。

在事实底稿保留简短的时效表：`关键字段｜数值/期间｜实际数据时点｜公告时间｜来源｜本次核验时间｜最新性证据/缺口`。只有确认来源中没有截至基准时刻更晚的适用披露，才称其为“最新已披露”；来源不可访问或检索不完整时写明未完成核验，不把“没搜到”写成“没有新公告”。

### 3.3 标准声明

在市场现状快照开头固定输出：

```text
数据时效：分析基准时刻 YYYY-MM-DD HH:MM 时区 | 行情截止 <交易日与时间、盘中/收盘/延迟/停牌> | 最新已披露财报期 <期间>、公告日 <日期> | 期后公告核验至 <时间> | 最终核验时间 <时间> | 币种/单位 | 主要来源 | 时效缺口 <无/具体缺口>
```

## 四、标准查询模式

以下问句是模板，可用于问财或通用搜索，不要求逐字照抄，但必须保留时间口径与核心字段。执行时将“今日”绑定到实际日期和时区，要求结果返回实际数据时间；“最新报告期”须与官方披露列表核对，不能把问句里的“最新”当成结果已通过时效验证。历史时点分析改为截至基准时刻的明确日期与区间。

### 4.1 A 股个股市场现状

1. 大盘环境

```text
上证指数最新价、沪深300市盈率、今日A股成交额、今日涨跌家数
```

2. 个股行情与估值

```text
贵州茅台 600519.SH 最新价、涨跌幅、成交额、换手率、总市值、市盈率TTM、市净率、股息率
```

3. 历史位置与技术状态

```text
贵州茅台近1年涨跌幅、52周高点和低点、20日均线、60日均线、120日均线、MACD、RSI
```

4. 最新财报口径

```text
贵州茅台最新报告期营收、净利润、ROE、毛利率、净利率、同比增速
```

5. 资金与分红

```text
贵州茅台主力资金流向、近一年分红、股东户数变化、机构一致预期
```

6. 行业 / 板块环境

```text
白酒行业估值排名、白酒行业盈利情况、白酒板块今日涨跌幅和主力资金净流入
```

### 4.2 港股市场现状

```text
泡泡玛特 09992.HK 最新价、涨跌幅、总市值、市盈率、近一年涨跌幅、南向持股、最新报告期营收和净利润
```

如果单个问句返回不足，可拆成两到三个更短的问句。

### 4.3 行业 / 板块筛选

```text
A股行业估值排名
主力资金净流入前十的板块
港股科技股中市盈率低于30倍且营收增长为正的股票
```

### 4.4 价值投资现金流底稿

先确认最新报告期和已披露的完整财年，再将下面的占位符替换成实际公司与明确年度区间。按字段组分别查询，返回不足时拆分年度：

```text
[公司名 + 代码 + 市场] [起始年度至截止年度] 各年度营业收入、归母净利润、经营活动现金流量净额、折旧摊销
[公司名 + 代码 + 市场] [起始年度至截止年度] 各年度购建固定资产无形资产和其他长期资产支付的现金、应收账款、存货、应付账款、合同负债
[公司名 + 代码 + 市场] 最新报告期货币资金、有息负债、总股本，以及最近五个完整财年现金分红、回购金额和股本变化
```

这些是查询意图模板，并不保证每个字段均受支持。保留原始财报项目名称；计算 `经营现金流净额 − 购建长期资产现金支出` 时标注为该口径下的简化自由现金流，核对并购、租赁和利息分类等差异。该结果不能直接等同于 FCFF、FCFE 或业主收益。

为正文图表准备同口径序列：最近 5 个完整财年、最新累计期与上年同期；有可核验单季数据时补近 8–12 季。每条记录保留 `指标｜值｜币种/单位｜起止日期｜年度/累计/单季/TTM｜合并范围｜会计/调整口径｜原始/重述版本｜来源/页码｜事实/计算/预测`。序列的可比性与缺失处理见 [公司业绩时间线](company-and-industry-trends.md)。

### 4.5 支撑经营假设与估值调整

财务快照之外，按主要利润来源补充以下材料；优先查公司经营披露和附注，供应商无字段时不编造字段：

- **经营驱动**：销量/净售价、客户留存/付费、产能利用率、订单交付与收款、分部利润；按目标公司的商业模式选取，不要求每家公司拥有所有指标。
- **投入与正常化依据**：资本开支项目和支付进度、研发/内容资本化、租赁支付、一次性损益、营运资金变化及税费；保留原始披露与分析调整的对应关系。
- **归属与资本配置**：受限现金、少数股东、投资持股、债务期限、在外股数与已公布股本变动，重大再投资/并购的原预期及后续结果。区分期末在外股数与 EPS 加权平均股数。
- **存量与增长对照**：现有业务的维护/更新需求、客户或产品寿命、已承诺建设与合同支出、新项目投入及回报、共享费用和退出成本；无法拆分时说明缺口，不按收入占比推断现金贡献。

每个估值输入标明是原始披露、计算结果还是分析假设，附报告期、公告日、来源页码或章节及缺口。重大未知须记录合理范围的证据、变量联动和是否影响结论；不能定界时标为暂不可估值，不用三档条件价格填补缺口。不能用“数据已拉取”替代经营模型和正常化推导。具体判断与推导见 [从商业判断到股东价值](business-to-value.md)。

### 4.6 行业增长与未来经营路径

先确定公司各主要业务实际参与的产品、地区及价值链环节，再按可比口径查询。以下是研究问题，不假定供应商都提供相应字段：

```text
[行业/产品 + 地区] [最近三至五个完整年度及最新同期] 行业销量、销售额、同比增速、渗透率、统计定义与原发布方
[公司/分部 + 相同产品和地区] [相同期间] 销量、收入、净售价和市占率，对应行业分母及来源
[行业/地区] 有效产能、利用率、价格和竞争格局变化，以及对行业利润率的影响
[行业/地区] 未来三至五年需求预测，发布机构、发布日期、预测期、主要假设及约束
```

行业历史与预测分表保存。预测须保留版本、原始区间和假设；无法找到可信预测时，从有证据的需求驱动建立定性路径，不用模型记忆补精确增速。公司多业务分别取数，不将集团收入增长与某一行业出货量直接比较。公司提供的行业研究也注明原发布者，识别宣传或选样限制。

## 五、问句改写规则

- 保留用户核心意图，不改变筛选条件。
- 口语化表达按研究意图拆解，例如价值投资中的“最近怎么样”优先查询经营、现金流、最新披露与估值变化；只有行情问题才查询涨跌幅、成交额等。
- 复合问题拆成少量独立问句，避免一个问句里塞入过多条件。
- 若首次返回为空，最多简化两次表述或拆分字段，并说明最终使用的问句；不放宽用户指定的标的、日期或筛选条件。

## 六、输出要求

- 所有市场数据都注明实际来源；模型已有知识仅能补充历史背景，并标注“未实时核验”。
- 每个关键字段必须附实际时间口径；无法确认时标明时效未通过，不用检索时间替代。
- 某项字段拿不到时，区分“公司未披露”“来源暂不可核验”“本次尚未完成核验”，列出影响哪些判断以及下一步核验路径；已查到可用公开来源的重要字段应先补核。不要把某字段缺失扩写为整家公司无法判断。
- 不默认读取历史知识库或旧报告；明确复盘时也先独立分析，旧数字和引文回查原始资料后才可作为事实使用。

## 七、边界与错误处理

| 情况 | 处理方式 |
|------|----------|
| 返回为空 | 简化表述或拆分字段重试，最多 2 次；保持标的、日期和用户条件 |
| 返回字段不全 | 拆分问句，优先保留核心字段 |
| 多个问句结果冲突 | 先统一证券、报告期、币种、单位与统计口径，再回查原始来源；无法解释时保留差异，不拼接成一个确定值 |
| 港股 / 财报字段不稳定 | 明确标注缺失，不补猜 |
| 数据商返回旧报告期或旧报价 | 查官方披露或其他来源更新；不得将旧值标为当前值 |
| 最新性或时间戳无法确认 | 标明时效未通过和受影响结论，继续局部研究，不给当前价格判断或候选 |

### 默认检索降级

问财或通达信不可用时：

1. 优先使用 Agent 的网页/搜索工具查找交易所、公司公告、定期报告、指数公司及可靠财经来源。
2. 其次使用用户提供的行情或财务数据，明确标为“用户提供”，并独立核对是否有更新的已公开信息；无法核验时不称最新。
3. 模型已有知识只用于商业模式、产业链和历史背景等相对稳定内容，不得作为当前股价、最新财报或公告事实。
4. 降级只改变数据获取渠道，不降低最新性要求。关键时效缺口仍存在时，交付局部分析与缺口，不沿用旧数给当前价格、安全边际或候选判断。

> 问财数据只用于辅助形成市场现状与估值判断，不替代对商业模式、管理层和长期竞争力的定性理解。
