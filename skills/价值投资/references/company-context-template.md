# 公司研究快照模板

仅当用户明确要求沉淀或收录本次研究时使用。保存的是带日期的研究记录，不是未来公司分析的默认依赖；日常分析不加载此模板或公司存档。每次研究仍须从本次核验的原始证据重新建立判断。

按实际资料取舍各节，不为填满模板编造引文、数字或评价。使用方法遵循主 skill 与同目录的 `business-to-value.md`；向 `companies/` 保存快照时如需方法链接，使用 `../business-to-value.md`。
