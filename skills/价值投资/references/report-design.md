# 投研报告视觉与信息设计

适用于本 skill 生成的独立 HTML 报告。默认采用克制、清晰、便于核验的研究文档风格；用户指定的风格和交付格式优先。设计服务于研究结论，不改变证据门槛、估值条件或结论状态。

## 参考与取舍

OpenDesign 的 [Quarterly Financial Report](https://open-design.ai/showcase/quarterly-financial-report-design/) 提供了文档式画布、简短摘要、关键指标、图表与比较表格逐层展开的参考；[Data Visualization Report](https://open-design.ai/plugins/example-data-report/) 和 [DCF Valuation](https://open-design.ai/plugins/example-dcf-valuation/) 可作为数据报告及估值页面的形式参考。这些是视觉案例，不是公司事实或估值方法；案例中的数字为示意，不能带入研究。财务报告案例自身指出其示意图缺少月份和数值刻度，实际报告须补齐可核验的坐标及数据。

无需为每次生成报告调用 OpenDesign 或依赖联网模板：以下规范可直接实现；若用户明确要求使用 OpenDesign 生成，则遵循其实际可用的工作流，并仍执行本 skill 的证据、离线与交付要求。

## 阅读顺序与版式

- **首屏先说人话**：公司与代码、基准时刻和最终核验时间之后，以完整短句说明公司现状、关键理由及当前能作出的判断；紧接已确认的证据、最关键的未知和下一次验证信号。状态标签、置信度与估值条件放在次一级，不将“数据不足：继续观察”或“暂不可估值”单独作为大标题。缺口须说明影响业务、每股价值还是现价比较，避免把所有判断一并隐藏。
- **指标有上下文**：挑选与论点相关的少量指标，不为了填满卡片而重复数字。每项紧邻单位、期间、比较基准与来源；行情显示时间和延迟状态。投资判断不依赖颜色识别。
- **由摘要进入证据**：完整报告用章节导航和一致的标题层级，依次展开业务、公司多年趋势、行业对照与未来路径、三要素及现金流估值、反证与跟踪条件。每节先用一句发现提示阅读，事实、计算、指引和研究假设明确标识；反复出现的会计口径提醒集中到就近图注或附录。
- **术语就地解释**：首次出现“正常化现金流”时解释为剔除暂时波动、扣除必要投入后可持续的现金，并说明归属；FCF、ROIC、TTM 等也先写中文含义。正文以“这些变化对未来赚钱和股东回报意味着什么”为主，计算明细可折叠但不能藏起决定结论的证据。
- **文档式而非交易终端**：居中单栏正文，宽屏可对相关图表或证据使用双栏；窄屏自然叠成单栏。避免大面积空白封面、花哨动效、密集仪表盘、装饰性图片及无法解释的评分仪表。快速判断可只用摘要、关键证据与缺口。

## 视觉基线

可按公司及任务调整，以下是可直接套用的默认方向：

- 画布以白色或暖白为主，正文深墨色；用深蓝作为结构强调，琥珀色标识待验证、暗红标识风险。语义颜色配文字，避免只用红绿表达涨跌或好坏。图表配色在白底和打印灰度下仍可区分。
- 正文采用本机中文无衬线字体栈，标题可使用本机中文衬线字体栈；回退到系统字体，不加载远程字体。正文建议约 16–18px、行高 1.6–1.8；来源和表注不小于约 12px。使用字重、间距和细分隔线建立层级，不靠连续大色块。
- 居中内容宽度建议约 960–1100px，正文段落保持舒适行长；有清晰的章节间距、有限边框和轻微底色。表格数字右对齐并使用等宽数字，负数与缺失值标记一致，附币种、单位及期间。比较表中突出与论点相关的行，避免全部加粗。
- 采用语义化标题、表头、链接和可见键盘焦点；正文与背景对比度至少 4.5:1，大字至少 3:1。链接文字说明目的地，避免仅以图标表达含义。

## 图表与证据

完整报告默认用图表回答“这些年表现怎样、利润是否变成现金、公司相对行业如何”三个问题；有可比数据时实际画出趋势，不能只给原始数字表或最近一期快照。具体期间和行业取数见 [公司与行业时间线](company-and-industry-trends.md)。快速判断或确实缺数据时按任务缩减，并解释缺口。

| 表达目的 | 优先形式 | 阅读要求 |
|---|---|---|
| 多年收入、盈利与回报 | 共用时间轴的小多图、折线或分组柱图 | 收入与利润数量级差异大时分面；年度、最新同期和 TTM 分开 |
| 利润与现金转化 | 同期并列图；完整调节底稿支持时用瀑布图 | 瀑布起点、每项调整和终点必须勾稽；只知道部分项目时用调节表，不画假闭环 |
| 分部贡献与变化 | 横向分组柱图或包含“其他/抵销”的构成图 | 分清收入、毛利与经营利润；有负贡献时不强塞饼图 |
| 公司与行业比较 | 同口径增速/份额折线、基期指数图或小多图 | 标明地区、产品、量/额口径与基期；不可比时不共用对比线 |
| 有依据的未来情景 | 历史实线 + 情景虚线/区间，或驱动因素表 | 预测起点、假设来源与年份清楚；无数值依据时不画延长曲线 |
| 风险及后续验证 | 简短表格 | 当前基线、改善/恶化条件、判断影响与检查时点 |

图标题写可检验的发现或问题，每图附 1–2 句解释变化原因及未来意义；相邻明细表承担复核，不要求读者从整页数字自行寻找结论。不要为完成图表数量而堆重复视图。

每张图标明指标、币种/单位、期间、来源及必要的口径说明，坐标和刻度可读；关键数值可从相邻表格或文本核对。历史与预测用线型/填充及文字同时区分，缺失数据留空或断线；不要以截断坐标、面积或夸大精度误导。估值图必须服从估值条件，暂不可估值时展示缺口与经营门槛，不画无依据的目标价区间。静态图优先内联 SVG 或 CSS；交互控件是补充，默认状态和无脚本状态下仍可读可核对。

柱图从零起点，正负数据共用真实零线；折线若缩窄纵轴范围须清楚标刻度且不夸大变化。避免双轴制造相关性，金额与比率优先分面。同一指标跨图保持单位、颜色/线型与口径一致，关键值直接标注，不能只有悬停才能读数。SVG 提供可理解的标题/说明或等价文本表，图表与相邻表格来自同一份底稿。

## 移动端、打印与验收

- 窄屏不产生整页横向溢出；宽表放在有明确提示的局部横向滚动容器，关键结论与来源仍易查阅。图表可缩放或转为表格，不压缩到标签不可读。
- 提供 `@media print`：白底深色文字、隐藏纯导航/交互控件，保留结论、假设、图表、表格及来源；避免标题与正文孤立、表头脱离数据或图表被不必要地截断。打印时宽表须适配页面或重排，不能只打印滚动容器的可见部分。关键内容不要只放在默认关闭的 `<details>` 中；若使用折叠，确保打印输出完整。
- 交付前核对图表与表格数值一致、来源链接可用、事实与预测标识清楚；有浏览器时分别检查桌面、窄屏和打印预览，检查标题、表格、图表与来源是否被遮挡、截断或分页拆散。无法预览时明确说明，仍完成静态检查。
- 做一次阅读验收：只读首屏和图标题，能否理解公司是在改善还是恶化、行业增长如何影响它、现在能判断到哪里，以及下一步具体看什么？如仍只能读到“观察/数据不足”，先改结论表达再交付。
