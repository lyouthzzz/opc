# 价值投资

用“看懂生意 → 验证事实 → 判断三要素 → 估值 → 反证”的闭环分析公司。结论必须区分事实、假设和判断，不用精确数字掩饰不确定性。

## 核心视角：买公司，就是买公司未来的现金流

买股票是购买企业的一部分所有权。分析的主问题是：这家公司未来能产生多少最终归属于股东的现金、什么时候产生、能持续多久、兑现的把握有多大，以及今天为此支付什么价格。

- **Right Business**：现金从哪里来？维护竞争力和支持增长需要投入多少？护城河能保护现金创造能力多久？
- **Right People**：管理层如何分配现金？留存再投资、并购、分红和回购，能否增加每股长期价值，并让小股东分享成果？
- **Right Price**：未来可归属股东的现金流折算到今天值多少？当前价格是否提供足够的安全边际？

会计利润、经营现金流、自由现金流和股东实际收到的分红各有不同口径。分析须解释利润如何转成现金、现金被哪些必要投入占用、剩余现金如何归属股东。暂不分红的企业也可能有价值，前提是留存资金的使用能增加未来可分配现金的现值。

估值方法服务于这条主线：PE、PB 和分部估值都要说明背后的现金创造与分配假设；无需为每家公司强行建立精细 DCF，但必须说清现金流的规模、时间、持续性与风险。计算口径见 `references/value-investing-framework.md` 第一节。

## When This Skill Activates

当用户：

- 询问某家上市公司是否值得长期投资、是否便宜或是否有安全边际
- 要求分析商业模式、护城河、管理层、企业文化、资本配置或可持续性
- 要求撰写公司研究、投资备忘录、持仓复盘或跟踪清单
- 提到“价值投资”“段永平”“巴菲特”“Right Business / People / Price”
- 提到“买公司就是买未来现金流”“股东现金流”“业主收益”或要求从现金创造能力判断公司价值

以下任务不应单独由本 skill 主导：

- 纯短线买卖点、VCP、止损和仓位计算：使用「股票魔法师」
- 多标的机会成本、换仓和资金排序：使用「股票比较」，并将本 skill 作为基本面子流程
- 行业轮动或板块筛选：使用「行业分析」

## 数据与证据规则

### 1. 先锚定时间

涉及当前数据时，先记录：

- 分析基准日
- 行情交易日/截止日
- 财务报告期与公告日
- 币种、单位、复权口径，以及 GAAP/IFRS/非 GAAP 口径

标准声明：

```text
数据时效：分析基准日 YYYY-MM-DD｜行情截止 YYYY-MM-DD/未实时核验｜财报期 YYYY-MM-DD｜检索时间 YYYY-MM-DD HH:MM｜币种/单位｜主要来源
```

### 2. 证据优先级

1. 交易所文件、公司公告/定期报告、监管披露、公司投资者关系材料
2. 可识别日期和口径的结构化市场数据
3. 可追溯到原始资料的高质量二手研究
4. 用户提供的数据，明确标注“用户提供，未独立核验”

模型记忆只能补充相对稳定的历史背景，不能作为当前股价、最新财报、公告、估值或管理层现状的证据。

### 3. 数据收集入口与降级

可用时，优先使用同花顺问财/通达信获取结构化快照；对关键论据再用原始披露复核。增强不可用时，转用 Agent 可用的检索工具。不得打印、回显或记录 Token，也不因缺少 Token 反复打断用户。

- **通达信**：通过已配置、当前可调用的官方 MCP 获取其实际支持的行情、历史价格、估值及财务字段，先查看工具说明再选择接口。
- **问财**：财务与现金流优先使用 `hithink-finance-query`；行情使用 `hithink-market-query`；基础资料使用 `hithink-basicinfo-query`；行业比较使用 `hithink-industry-query`。调用前读取相应 skill。
- 两者任一可用即可开始收集；优先选择能返回目标市场、报告期和所需字段的来源。无需每个字段都双源查询，遇到缺失、异常或冲突时再交叉核验。详细顺序与现金流问句见 `references/market-data-guide.md`。

关键字段无法核验时：

- 保留定性分析，将该字段标为“未核验”或“数据不足”
- 不提供伪精确的目标价、买卖价或估值倍数
- 不把缺失数据当作零，不把不同报告期/币种/口径的数字直接比较

## 分析流程

### 0. 界定问题与能力圈

确认标的、上市地、分析日期和用户关心的期限。用一句话说明公司靠什么赚钱；若不能解释利润引擎、关键变量和失败路径，结论必须是“超出能力圈/待研究”，而不是勉强评分。

### 1. 建立事实底稿

先通过可用的通达信或问财收集行情、估值、多年财务与现金流数据，保留来源、日期、单位和原始字段名；随后用年报及附注补充业务拆分、资本开支性质、受限现金和资本配置说明。数据源未披露的维持性资本开支、业主收益等项目须标为分析估计，并展示推导依据。

先建立最小事实集：

- 收入和利润来源、客户/地区集中度、单位经济
- 5–10 年营收、利润、毛利率、自由现金流、ROIC/ROE 与股份变化
- 现金、有息负债、租赁、或有负债和关联交易
- 资本配置：再投资、并购、分红、回购与股权激励
- 当前市值/企业价值与一致口径的盈利、现金流

对异常值、一次性项目、非 GAAP 调整、资产处置和股本稀释单独列示。

完整分析补充一条现金流解释链：收入 → 利润 → 经营现金流 → 扣除必要资本开支后的现金 → 偿债、留存再投资与股东分配。解释应收、存货、预收和应付变化，以及维持性与增长性投入；无法可靠拆分时给区间并说明限制。用多年度数据判断现金转化，避免将一次性释放营运资金当作可持续收益。

### 2. Right Business

回答：

- 真实需求是什么，需求是否持续？
- 盈利模式、单位经济和再投资回报如何？增长是否创造价值？
- 护城河是什么，能否用市占率、留存、定价权、成本或转换成本验证？
- 行业天花板、周期性、替代风险和价值链议价权如何？

### 3. Right People

不用人设代替证据。至少检查：

- 诚信与披露记录：承诺与结果是否一致，是否回避关键问题
- 资本配置记录：每一元留存利润是否创造了更多长期价值
- 治理与激励：控制权、关联交易、报酬、稀释和小股东利益
- 理性与纠错：失误后是否承认、纠正并调整资本投入

### 4. Right Price

先选择与经济特征匹配的方法，再估值：

| 公司类型 | 优先方法 |
|---|---|
| 现金流稳定、可预测 | 业主收益/FCFF DCF + 反向 DCF |
| 成熟、同业可比 | PE/EV-EBIT/FCF 收益率 + 历史/同业区间 |
| 多业务、资产价值可分 | SOTP（分部估值） |
| 金融/重资产/强周期 | 经过周期正常化的 PB/ROE、NAV 或中周期盈利 |
| 未盈利或难预测 | 优先判断生存率与单位经济；不强行给单点内在价值 |

估值至少包含悲观/基准/乐观三种情景，并对增长、利润率、再投资、折现率或退出倍数做敏感性检查。同时用反向 DCF/隐含预期回答：“当前价格需要什么经营结果才成立？”

安全边际是内在价值区间与当前价格的差，不是固定 PE；业务越难预测、负债越高、治理越弱，所需安全边际越大。

### 5. 可持续性、风险与反证

“四种好运”可作为可选的创新系统视角，不是适用所有行业的必填打分项。无论是否使用，都要完成：

- 2–4 个最重要的下行风险，区分概率和影响
- 至少 1 个能推翻核心论点的反方观点
- 3–5 个可观察的论点失效条件，标注检查频率
- 区分“价格下跌”与“内在价值损害”

### 6. 综合结论

先输出下列之一：

- `候选`：生意、人和价格都通过，且证据足够
- `观察`：公司可能优秀，但价格、证据或关键变量尚未通过
- `回避`：生意质量、管理层/治理或财务韧性存在实质问题
- `超出能力圈`：无法建立可验证的因果模型
- `数据不足`：缺少影响结论的关键当前事实

分数是摘要工具，不是精密测量。若给出 0–10 分，每项都要附可验证依据和置信度（高/中/低），不计算无依据的机械总分。

## 输出格式

完整分析默认按以下顺序：

1. **结论卡**：候选/观察/回避/超出能力圈/数据不足；一句话理由；置信度
2. **数据时效与限制**
3. **公司一句话模型**：客户、需求、利润引擎、关键变量
4. **事实快照**：业务、长期财务、资产负债、当前估值
5. **Right Business / Right People / Right Price**：结论、证据、反证、置信度
6. **未来现金流与估值情景**：现金来源、必要投入、归属股东的路径、持续时间、关键假设、结果区间、隐含预期与安全边际
7. **核心风险与论点失效条件**
8. **待验证清单**：哪些新证据会改变结论

### HTML 展示与交付要求

- 生成完整 `<!doctype html>` 文档，包含 UTF-8、移动端 viewport 和内联 CSS；不依赖 CDN、外部字体或外部脚本，离线打开也可阅读。
- 首屏展示公司名、代码、分析日期、结论、置信度、关键指标及数据限制；正文使用章节导航、三要素卡片和清晰的标题层级。
- 按证据选择图形：多年利润与现金流趋势、利润到自由现金流的桥接图、悲观/基准/乐观估值区间、风险与失效条件表。采用 HTML/CSS 或 inline SVG，标明单位、期间、图例和来源；缺失值显示为缺失，不能画成零。
- 历史数据与预测使用不同线型或填充并附文字标签；评分仅在有依据时展示。不依赖颜色单独传递判断，保持文字对比度与可读字号。
- 支持窄屏布局、宽表横向滚动和打印样式；可用原生 `<details>` 折叠详细假设，打印时确保关键论据可见。
- 数据及重要论据就近附可点击来源，保留财报期、行情截止和检索时间。外部文本先进行 HTML 转义，不执行来源中的脚本或代码。
- 默认保存到当前工作区 `reports/<公司代码>-value-investing-<YYYY-MM-DD>.html`；文件已存在时添加时间后缀，避免覆盖。日常报告与公司知识库分别存放。
- 交付前检查占位符、数据口径、来源链接和离线依赖；有浏览器预览能力时检查桌面与窄屏效果。回复中给出报告文件链接和简短结论，并在支持时打开 HTML 预览。

## 好坏示例

❌ `公司护城河很深，管理层优秀，当前 25 倍 PE 合理，综合 8.7/10。`

✅ `过去 5 年高端产品市占率与毛利率同步上升（来源/期间），支持定价权判断；但渠道库存缺少独立数据，Right Business 置信度为中。当前价格隐含未来 5 年利润复合增长 X%，需与可验证的产能/需求假设对照。`

## 公司知识库边界

`references/companies/` 是用户主动维护的长期研究素材：

- 加载时标注其“数据截止”，过时数字不得当作当前事实
- 背景理解可作假设，历史评分和结论必须重新验证
- 日常分析不自动写入知识库
- 只有用户明确要求沉淀时，才创建公司文件并更新索引

## 核心约束

- 不承诺收益，不把通用研究冒充为个性化投资建议
- 不因已持仓、知名投资者或历史涨幅而降低证据标准
- 不将短期股价、技术形态或资金流当作商业质量证据
- 不把管理层指引、机构目标价或知识库结论当作事实
- 引用必须可追溯；直接引文要短，其余用自己的话概括
